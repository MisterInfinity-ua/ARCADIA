# 🕹️ ARCADIA — Ultimate Browser Game Hub & Minecraft 3D

> **35 Hand-Crafted Browser Games · Zero Downloads · 100% Free · 60 FPS Canvas Performance**

ARCADIA is an ultra-fast, zero-bloat browser game hub featuring 35 original games, including the brand-new **Minecraft 3D Voxel Engine** (with procedural terrain, mobs, crafting, TNT physics, and world saves), **DOOM 3D FPS**, **Crossy Cyber**, **Cyber Dash**, **Retro Drift**, **Cyber Jumper**, **Neon Tank War**, **Galaga Fighter**, **Connect Four**, **Chess Master**, **Wordle Arcade**, **Tower Defense**, **Cyber Surfer**, **Laser Maze**, and classic arcade hits.

## ⚡ Key Features

- **Minecraft 3D Voxel Sandbox**: Full procedural voxel world generation with caves, mobs, crafting, and persistent localStorage saves.
- **Web Audio Synthesis**: Procedural 8-bit retro sound effects generated directly in the browser with 0 external audio files.
- **Arcadia Passport & Achievements**: Profile leveling system, EXP points, high scores tracking for all 35 games, and 25 unlockable achievements.
- **Virtual On-Screen Touch Controls**: D-Pad and Action A/B buttons for phones, tablets, and arcade mode.
- **Instant Search & Category Filters**: Filter by 3D, Action, Arcade, Puzzle, Rhythm, or Favorites with real-time text search and sorting.
- **Random Game Roulette (🎲)**: One-click "Surprise Me" feature with animated slot-machine selection.
